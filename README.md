## 🚀 How to Run Locally

You can simply double-click `index.html` to open it in your browser (Chrome, Edge, Safari, Firefox).

Alternatively, launch with any local static server:
```powershell
# Using Python (if installed)
python -m http.server 8000

# Using Node / npx (if installed)
npx serve .

# Or open directly in Edge / Chrome
start index.html
```
